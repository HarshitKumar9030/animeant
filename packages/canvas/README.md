# @animeant/canvas

Canvas2D renderer for [Animeant](https://github.com/HarshitKumar9030/animeant) figures.

```bash
npm install @animeant/core @animeant/canvas
```

```ts
import { CanvasRenderer } from "@animeant/canvas";

const renderer = new CanvasRenderer(canvasElement);
renderer.draw(figure);
```

See the [main README](https://github.com/HarshitKumar9030/animeant#readme) for the full API.
