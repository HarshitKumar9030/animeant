# Changelog

## 0.1.0

First release of `@animeant/core` and `@animeant/canvas`.

- Node graph with lazy world matrices, joint limits and JSON rigs.
- Inverse kinematics: FABRIK and CCD chains that only write rotations.
- Tweens with easings, cubic-bezier and damping.
- JSON clips played by a layered animator: crossfades, override and additive layers, root motion.
- Physics: spring chains for secondary motion, and a verlet ragdoll with grab, drag and fling.
- Fixed-step ticker.
- Canvas2D renderer with per-bone widths and editor overlays.
